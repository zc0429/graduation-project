# 参考文献管理

采用「双轨制」管理参考文献，适配 Word 撰写论文的工作流，全部文本文件随 Git 版本化。

## 目录说明

| 文件/目录 | 用途 | 是否入库 |
|---|---|---|
| `references.bib` | BibTeX 条目库（知网/学术搜索引擎导出后追加） | ✅ |
| `gb7714-list.md` | GB/T 7714-2015 国标格式文献清单（论文直接引用此格式） | ✅ |
| `pdfs/` | 文献原文 PDF | ❌（默认不入库，防止仓库膨胀） |

## 标准工作流

1. **检索**：从中国知网、万方、Google Scholar 检索文献
2. **存原文**：PDF 下载后放入 `pdfs/`，文件名建议 `第一作者-年份-短标题.pdf`
3. **登记 BibTeX**：知网文献详情页「导出与分析 → 导出文献 → BibTeX」，追加到 `references.bib`
4. **登记国标格式**：按 `gb7714-list.md` 中的示例格式，手写/改写一条 GB/T 7714 记录并编号
5. **论文引用**：Word 中采用「顺序编码制」，正文标注 `[1]`，文末参考文献从 `gb7714-list.md` 复制

## 常见问题

- **想用 Zotero？** 可以。用 Zotero 收集后导出 BibTeX 覆盖 `references.bib`，再导出 GB/T 7714 格式条目更新 `gb7714-list.md`
- **PDF 想入库？** 删除根目录 `.gitignore` 中 `docs/references/pdfs/*` 一行即可
- **引用数量**：本科毕设一般要求 15 篇以上，含一定比例近 5 年文献与英文文献，以学校要求为准
