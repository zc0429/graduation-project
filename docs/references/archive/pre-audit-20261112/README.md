# 参考文献管理

采用“BibTeX 主库 + GB/T 7714 顺序编码清单”双轨管理，适配 Markdown 源稿与后续 Word 排版工作流。最终论文的著录格式以 `docs/materials/附件2：云南工商学院本科毕业论文（设计）.docx` 为准。

## 目录说明

| 文件/目录 | 用途 | 是否入库 |
|---|---|---|
| `references.bib` | BibTeX 元数据主库，顺序与国标清单一致 | ✅ |
| `gb7714-list.md` | GB/T 7714-2015 国标格式文献清单（论文直接引用此格式） | ✅ |
| `pdfs/` | 文献原文 PDF | ❌（默认不入库，防止仓库膨胀） |

## 当前冻结口径

- 学校要求毕业论文参考文献一般不少于 20 篇，其中近三年不少于 15 篇、外文不少于 2 篇；正文采用顺序编码制。
- 当前主清单共 24 篇，其中中文 18 篇、外文 6 篇，2024—2026 年文献 16 篇。中文近年教育研究构成主体，外文仅保留必要的基础研究与综述。
- Spring Boot、Vue.js、MyBatis-Plus 官方文档属于实现资料，不计入 24 篇学术参考文献，不以技术文档充抵学校数量指标。
- 旧清单缺页码的刘畅（2025）和郑伊彬、叶新东（2025）已移出主库；贾洪愿等（2025）已按出版商 PDF 补齐页码并纠正作者顺序。最终核验同时修正了 Sessler 姓名拼写，以及刘邦奇等（2024）的作者、页码和 DOI。

## 标准工作流

1. **检索**：优先使用期刊官网、出版社官网、开放学术数据库与学术搜索平台发现候选文献，不预设文献必须来自某一商业数据库。
2. **核验**：用 DOI 落地页、Crossref、期刊官网、出版社 PDF 或 arXiv 原始记录交叉核对作者、题名、年份、卷期、页码或文章号；无法核实的字段不得补写。
3. **登记**：先更新 `references.bib`，再按学校规范生成 `gb7714-list.md`；两者的条目数量、顺序和元数据必须一致。
4. **同步引用**：调整编号后同时检查 `docs/thesis/毕业论文.md`、`docs/thesis/开题报告.md`、任务书及其他含 `[n]` 引用的 Markdown 文件。
5. **留存原文**：允许下载的 PDF 放入 `pdfs/`，文件名建议为 `第一作者-年份-短标题.pdf`；该目录默认不入库。
6. **导出复核**：Word 导出时再次核对外文作者国籍前缀（含中国作者以外文形式发表时的“（中）”）、中文全角标点、悬挂缩进、正文角标和跳转。

## 常见问题

- **想用 Zotero？** 可以。用 Zotero 管理来源并导出 BibTeX，但导出结果仍需与期刊或出版社原始元数据复核。
- **PDF 想入库？** 删除根目录 `.gitignore` 中 `docs/references/pdfs/*` 一行即可
- **为什么不保留无页码期刊文献？** 学校正式规范要求期刊著录起止页码；若正式来源无法核实，优先换用元数据完整的真实文献。
