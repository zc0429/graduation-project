# 参考文献清单（GB/T 7714-2015）

按「顺序编码制」编号，论文正文中以 `[1]`、`[2]` 形式标注，文末按此清单排列。
以下为各类型文献的格式示例，替换为真实文献后删除本说明。

## 格式示例

**期刊论文 [J]**

> [1] 张三, 李四. 基于Spring Boot与Vue的前后端分离Web系统设计与实现[J]. 软件工程, 2023, 26(5): 45-49.

**专著 [M]**

> [2] 王五. 软件工程导论[M]. 6版. 北京: 清华大学出版社, 2021: 120-135.

**学位论文 [D]**

> [3] 赵六. 基于深度学习的图像识别系统研究与实现[D]. 北京: 北京邮电大学, 2022.

**会议论文 [C]**

> [4] Vaswani A, Shazeer N, Parmar N, et al. Attention is all you need[C]//Advances in Neural Information Processing Systems. Long Beach: NeurIPS, 2017: 5998-6008.

**电子资源 [EB/OL]**

> [5] Spring. Spring Boot Reference Documentation[EB/OL]. (2024-03-01)[2026-07-21]. https://docs.spring.io/spring-boot/docs/current/reference/html/.

**标准 [S]**

> [6] 中华人民共和国国家质量监督检验检疫总局, 中国国家标准化管理委员会. 信息与文献 参考文献著录规则: GB/T 7714-2015[S]. 北京: 中国标准出版社, 2015.

## 著录要点

- 作者超过 3 位时，中文写「等」，英文写「et al.」
- 英文文献作者：姓在前全称，名缩写（如 `Vaswani A`）
- 电子资源需标注「发布或更新日期[引用日期]」与获取网址
- 文献类型标识：期刊 `[J]`、专著 `[M]`、学位论文 `[D]`、会议 `[C]`、报纸 `[N]`、标准 `[S]`、电子资源 `[EB/OL]`
