# 知错前端架构与设计说明

## 1. 文档范围

本文描述 `web/` 当前实现的页面架构、角色边界、数据流、视觉变量、共享组件、响应式策略和验收入口。它记录“前端实际能做什么”，不扩写后端尚未提供的班级、课程、历史报告或权限管理能力。

前端设计目标有四项：

1. 让学生围绕“录入、解析、重做、复习、反馈”完成闭环，而不是呈现通用管理后台。
2. 所有统计、状态和模型标识均来自真实接口；加载失败不能伪装成空数据或 0。
3. 学生、教师、管理员只看到其真实可用入口，同时明确前端守卫不等于服务端鉴权。
4. 同一套页面外壳覆盖桌面、平板和手机，并保留键盘、读屏与减弱动效支持。

## 2. 总体架构

```text
Vue 页面 / 共享组件
        │
        ├── Pinia 会话状态
        ├── Vue Router 路由与角色守卫
        └── 按领域拆分的 typed API
                    │
              Axios 请求层
        JWT 注入 / REST 解包 / 错误归一化
                    │
            Vite /api、/uploads 代理
                    │
           Spring Boot REST 服务
```

页面不直接拼接后端响应。`src/types/api.ts` 描述领域类型，`src/api/` 封装接口，`src/utils/request.ts` 统一处理 JWT、`{ code, message, data }` 解包、401 会话失效、Blob 下载与 API 错误。

| 路由 | 页面 | 学生 | 教师 | 管理员 |
|---|---|:---:|:---:|:---:|

| `/review` | 到期/逾期复习计划 | 是 | 否 | 否 |
| `/report` | 学情周报 | 个人范围 | 全站聚合 | 否 |
| `/message` | 消息中心 | 是 | 是 | 是 |
| `/announcement` | 公告；管理员可发布 | 查看 | 查看 | 查看/发布 |
| `/profile` | 当前账号资料 | 是 | 是 | 是 |
| `/admin/user` | 用户查询与逻辑注销 | 否 | 否 | 是 |

登录页为公开路由。其余路由在进入前调用 `ensureSession()` 校验恢复的 JWT；缓存用户 JSON 损坏时会清除无效缓存。401 会统一退出并携带原地址回到登录页；瞬时网络失败不会被误判为令牌失效。无权路由返回当前角色首页并显示说明，未知地址进入应用内 404。

## 5. 三角色真实业务边界

### 5.1 学生

- 录入错题：科目、知识点、题干、答案、来源和可选图片；图片只接受 PNG/JPEG/GIF/WebP，最大 10 MB，并在提交前本地预览。
- 错题本：分页、科目/知识点筛选、详情入口和 Excel 导出。
- 错题详情：显示真实科目、知识点、难度、掌握度和模型标识；支持编辑、删除和答案展开。
- AI 解析：触发异步解析后非重叠轮询，默认每 2 秒查询，最长等待 90 秒；连续可重试错误采用退避，并区分等待、成功、模型失败、超时和查询异常。
- 变式题：同步生成调用期间锁定重复操作，客户端最长等待 60 秒；学生可提交答案、正确性自评和用时。
- 复习：只处理后端返回的到期或逾期未完成计划。“标记计划完成”与“提交一次练习记录”为两个独立动作，界面分别说明。
- 练习历史：展示接口实际返回的记录。当前响应不含完整题干，因此只能按记录编号、题目/变式 ID、结果和时间呈现。
- 报告：显示当前学生的周统计、薄弱知识点和趋势；ECharts 图形同时提供文字趋势与表格替代。

编辑题干、答案、科目、知识点或图片后，旧 AI 解析会标为过期并隐藏。旧变式题同样隐藏，因为当前生成接口只追加记录，不能安全替换；后端提供清理/替换能力前，不混合展示新旧结果。

### 5.2 教师

教师只有后端周报接口提供的全站聚合统计、薄弱知识点和趋势。系统尚无班级表、课程关系、任课关系、学生列表或钻取接口，因此教师页不显示班级下拉框、学生详情、作业布置等虚构入口。

### 5.3 管理员

- 用户：分页查询和逻辑注销。
- 科目：查看、新增、编辑。
- 知识点：按科目维护两级树，新增节点并删除允许删除的叶节点。
- 公告：查看和发布。

当前后端没有角色分配、账号恢复、科目删除、公告编辑/下线接口，前端不绘制对应按钮。

## 6. 请求、错误与文件下载

### 6.1 普通 REST 请求

Axios 实例以 `/api` 为根路径，默认超时 15 秒。请求拦截器从本地会话读取 JWT 并写入 `Authorization: Bearer …`。响应层仅在业务 `code === 0` 时返回 `data`，其余情况归一化为 `ApiError`；页面可以用 `silent` 关闭全局提示并展示局部错误。

### 6.2 Excel Blob 导出

Excel 不能走普通 JSON 解包，因此使用独立认证下载流程：

1. 组装 `/api/question/export` 及科目/知识点筛选参数。
2. 显式携带当前 JWT，以 Blob 接收响应，最长等待 60 秒。
3. 对非 2xx 或 JSON Content-Type 解析业务错误，避免把错误 JSON 保存成 `.xlsx`。
4. 从 `Content-Disposition` 读取并清理文件名，兜底为“错题本.xlsx”。
5. 创建临时对象 URL 触发下载，随后立即释放。

真实联调会监听导出请求并断言存在 `Bearer` 头。

### 6.3 页面状态原则

`AsyncState` 统一表达 `loading`、`empty`、`error`、`forbidden`。多数据源工作台采用 `Promise.allSettled`：单个接口失败只标记对应区域，并保留其他已成功数据；全部失败才进入整页错误。任何失败都不能显示成“0 条”或“暂无数据”。

## 7. 视觉系统

视觉概念为“数字错题本 / 校勘学习台”，使用温暖纸色、深蓝墨色、朱砂订正、青玉完成和琥珀提醒，保持 light-only 主题。

|---|---|---|
| `--paper` | `#f7f1e7` | 页面纸张底色 |
| `--paper-deep` | `#eee3d3` | 轨道、分区与深纸色 |
| `--paper-bright` | `#fffdf8` | 卡片和输入面 |
| `--ink` | `#1d2b38` | 正文墨色 |
| `--ink-soft` | `#52616d` | 次级正文 |
| `--navy` | `#18344a` | 主导航、标题、主要按钮 |
| `--cinnabar` | `#b74332` | 订正、风险、低掌握度 |
| `--jade` | `#168172` | 完成、进步、高掌握度 |
| `--amber` | `#b87723` | 中等掌握度和提醒 |
| `--focus-ring` | `#168c7b` | 键盘焦点轮廓 |
| `--line` | `rgba(37, 78, 102, 0.16)` | 纸面分隔线 |

字体按本机可用字体降级：展示文字优先楷体，标题优先中文衬线，正文优先微软雅黑/中文无衬线，数字优先等宽字体并启用等宽数字。

掌握度语义固定为：`0–39` 朱砂低位、`40–69` 琥珀中位、`70–100` 青玉高位。颜色之外同时输出数值、标签和 `progressbar` 语义。

### 7.2 共享组件

| 组件 | 用途 |

| `AppTopbar` | 当前页说明、功能入口检索、消息和账号菜单 |

| `PageHeader` | 唯一页面一级标题、说明和操作区 |

## 8. 响应式与可访问性

### 8.1 响应式断点

- `> 1180px`：244 px 桌面侧栏，可手动折叠为 84 px；主内容最大宽度 1440 px。
- `701–1180px`：侧栏固定为 84 px 图标导航，内容自动单列或减少网格列数。
- `≤ 900px`：顶部功能检索和账号文字收起，保留可点击消息与头像。
- `≤ 700px`：隐藏侧栏，使用带安全区的五栏移动底栏和“更多”抽屉；主要按钮最小高度 44 px，弹窗限制在视口内。

Playwright 响应式用例覆盖 1600×1200、1280×800、820×1180 和 390×844。布局断点与设备名无关，依赖可用宽度。

### 8.2 可访问性约束

- 页面只有一个语义 `h1`，共享页头通过 `aria-labelledby` 关联。
- 提供“跳到主要内容”链接；路由切换后滚动并聚焦主内容。
- 导航使用 `nav`、`aria-current`、可读标签和未读数量说明。
- 加载状态使用 `aria-busy`/`aria-live`，错误和权限提示使用 `alert`。
- 表单使用显式标签，图片错误就地宣告；自定义按钮保持键盘可操作。
- 全局 `:focus-visible` 使用高对比青玉轮廓，不移除浏览器焦点反馈。
- 图表有文字摘要、数据表或 `role="img"` 文本替代，不只依赖 Canvas。
- `prefers-reduced-motion: reduce` 下取消页面进入、卡片和进度动画，并关闭平滑滚动。

axe-core 自动化是基线检查，不能替代键盘顺序、读屏语义和 200% 缩放的人工走查。

## 9. 性能策略

- 所有路由页面使用动态 `import()`，只加载当前入口。
- 报告页按需载入 `echarts/core`、Bar/Line、Grid/Tooltip 和 CanvasRenderer，不在应用首屏打入完整 ECharts。
- 图表使用 `ResizeObserver` 响应容器，页面卸载时断开观察并 `dispose()` 实例。
- AI 轮询不重叠，定时器在作用域销毁时清理；题目和变式请求以版本号丢弃迟到响应。
- 图片在提交前限制类型与 10 MB 大小，预览读取使用版本号避免竞态。
- 构建体积和 Lighthouse 分数必须以当次 `npm run build` 与报告为准，文档不保存会过期的旧分数。

当前 Element Plus 仍采用全局安装，构建时若继续出现主包体积警告，应在不破坏现有表单/弹窗行为的前提下评估按需导入；不能为了分数删除真实业务能力。

## 11. 后端已知限制与前端处置

| 后端限制 | 当前前端处置 | 完整修复方向 |
|---|---|---|
| 相似题候选未按当前用户隔离 | 停止调用和展示相似题，在详情页明确暂停原因 | 服务端查询强制绑定 token 用户并补跨用户测试 |
| RAG 参考候选隔离不完整 | 只显示后端返回的参考 ID，不展开题干 | 服务端统一用户隔离并返回可验证的安全引用模型 |
| 停用用户不撤销已签发 JWT | 只能在退出或收到 401 后清理本地令牌 | 增加 tokenVersion、黑名单或每次请求状态校验 |
| 教师无班级/课程/学生绑定 | 只展示全站聚合周报并标注范围 | 增加组织关系、授权查询和分层报告接口 |
| 周报不持久化历史版本 | 显示当前生成结果，不伪造历史列表 | 增加报告快照与时间范围查询 |
| 复习接口只给到期/逾期未完成项 | 不绘制未来日历 | 增加全量计划或指定日期范围接口 |
| 练习历史不返回题干摘要 | 按真实 ID 和结果展示，并说明信息范围 | 返回安全的题干摘要/题型/科目字段 |
| 变式生成只追加、无替换/清理 | 题目编辑后隐藏旧变式并禁止混合生成 | 增加按原题版本替换或归档能力 |
| 管理接口动作有限 | 只显示真实可用动作 | 逐项新增恢复、角色、删除、公告状态接口及鉴权 |

这些限制应进入后端修复清单；前端的隐藏、说明或路由限制只降低误用和泄露风险，不能被描述为服务端漏洞已经修复。
