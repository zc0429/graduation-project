# 导师参考文件

本目录用于存放**导师提供的各类参考文件**，与自行检索的学术文献（`docs/references/`）分开管理。

## 建议存放内容

- 任务书、开题报告模板
- 毕业论文格式要求 / 写作规范
- 往届优秀论文范例
- 导师下发的需求说明、批注文档
- 其他过程性材料（会议纪要、检查表等）

## 使用建议

- 保留原始文件名，或按 `日期-主题` 命名，如 `20260721-任务书.docx`
- 此类文件默认纳入 Git 版本管理，每次导师更新材料后直接提交，便于追溯历史版本
- 若单个文件超过 50MB，建议改用网盘保存，并在此文件中记录链接

## 当前论文材料权威层级

1. `附件2：云南工商学院本科毕业论文（设计）.docx`：学校《撰写规范及要求》，控制开题报告栏目要求、字体字号、行距、页面设置、引用与参考文献规则。
2. `参考论文/其他文档/开题报告.pdf`：导师提供的开题报告成品范例，控制正式导出件的表格结构、栏目顺序、签批区和整体视觉样式。
3. `毕业论文概要说明.pdf`：控制时间节点、软件工程过程与选题业务深度等过程要求；本项目后续数据库口径已按用户最终决定统一为真实 10 张物理表。

内容事实以冻结代码、数据库 Schema、控制器映射和 `docs/validation/` 证据为准。材料之间若出现早期估算与真实实现不一致，不得为迎合估算而改写实现事实。
