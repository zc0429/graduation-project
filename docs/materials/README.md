# 学校与导师材料

本目录用于存放**导师提供的各类参考文件**，与自行检索的学术文献（`docs/references/`）分开管理。

## 建议存放内容

- 任务书、开题报告模板
- 毕业论文格式要求 / 写作规范
- 往届优秀论文范例
- 导师下发的需求说明、批注文档
- 其他过程性材料（会议纪要、检查表等）

## 使用建议

- 保留原始文件名，或按 `日期-主题` 命名，如 `20260721-任务书.docx`
- 此类文件默认纳入 Git 版本管理，每次导师更新材料后直接提交，便于追溯历史版本
- 若单个文件超过 50MB，建议改用网盘保存，并在此文件中记录链接
