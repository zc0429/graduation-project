## 三、研究内容

### 1、拟研究解决的问题

- （1）错题知识点自动定位问题：研究基于大模型的知识点自动归类方法，构建两级知识点体系
- （2）解析质量问题：研究基于 RAG 的检索增强生成，降低大模型幻觉，保证解析准确
- （3）个性化复习问题：研究基于艾宾浩斯遗忘曲线的复习计划生成与相似题推荐算法
- （4）多角色权限问题：研究学生/教师/管理员多角色权限设计

### 2、系统功能清单（约 13 项）

| 模块 | 功能说明 |
|---|---|
| 用户管理 | 注册、登录、信息修改、注销；学生/教师/管理员多角色 |
| 科目管理 | 维护学科信息（数学、物理等） |
| 知识点管理 | 两级知识点体系维护（一级章节 / 二级考点） |
| 错题录入管理 | 文本录入、图片上传（OCR 识别为可选增强） |
| AI 解析管理 | AI 自动生成错题解析、知识点归类、难度评估，记录解析结果 |
| 相似题推荐管理 | 基于 Embedding 向量检索推荐同知识点相似题 |
| 变式题管理 | AI 基于原题生成变式练习，巩固薄弱点 |
| 复习计划管理 | 按遗忘曲线自动生成复习任务并推送提醒 |
| 练习记录管理 | 记录重做/变式练习的作答情况，更新掌握度 |
| 学情报告管理 | 周报生成：薄弱知识点分布、掌握度趋势可视化 |
| 错题本导出管理 | 按科目/知识点筛选导出 PDF/打印 |
| 消息通知管理 | 复习提醒、报告生成通知 |
| 公告管理 | 管理员发布系统公告 |

### 3、数据库设计（8 张表，满足"总 7–8 张表"要求）

`user`（用户）/ `subject`（科目）/ `knowledge_point`（知识点）/ `question`（错题）/ `ai_analysis`（AI 解析记录）/ `variant_question`（变式题）/ `review_plan`（复习计划）/ `practice_record`（练习记录）

业务流程闭环：录入错题 → AI 解析归类 → 推荐相似题/生成变式题 → 生成复习计划 → 练习反馈更新掌握度 → 学情报告。

## 四、研究方法、研究思路

### （1）研究方法

【待写：文献法（知网/万方查阅智能教育、推荐系统文献）＋ 实验法（开发中攻克 RAG 效果、提示词结构化输出等技术难点）＋ 比较法（对比作业帮等现有错题工具的优缺点）＋ 问卷调查法（面向同学的错题整理习惯调研）】

### （2）研究步骤

【待写：收集文献初步分析 → 需求调研 → 需求分析文档与技术方案（框架、数据库）→ 系统开发（前后端 + AI 模块）→ 测试（单元/集成）与测试报告 → 试运行维护 → 论文撰写】

- 软硬件：IntelliJ IDEA（后端）、VS Code（前端）、MySQL 8、Git、Windows 开发机
- 技术：Spring Boot 3 + MyBatis-Plus、Vue 3 + Vite + Element Plus、智谱 GLM 模型 API（开发联调阶段可临时使用兼容模型）+ Embedding 向量检索（如 pgvector/Milvus 或内存向量库）
- 知识：Java/Web 开发、数据库设计、提示词工程、软件测试
