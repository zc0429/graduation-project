## 三、研究内容

### 1、拟研究解决的问题

- （1）错题知识点自动定位问题：研究基于大模型的知识点自动归类方法，构建两级知识点体系
- （2）解析质量问题：研究基于 RAG 的检索增强生成，为模型提供本地参考上下文并记录参考题 ID；不将其表述为准确性保证
- （3）个性化复习问题：研究参考记忆规律的第 1、2、4、7、15 天固定节点复习计划与相似题推荐
- （4）多角色权限问题：研究学生/教师/管理员多角色权限设计

### 2、系统功能清单（约 13 项）

| 模块 | 功能说明 |
|---|---|
| 用户管理 | 学生公开注册、登录、资料修改；管理员查询并停用用户；三角色服务端鉴权 |
| 科目管理 | 维护学科信息（数学、物理等） |
| 知识点管理 | 两级知识点体系维护（一级章节 / 二级考点） |
| 错题录入管理 | 文本录入；默认关闭的单图 AI 识别回填，人工确认后保存 |
| AI 解析管理 | AI 自动生成错题解析、知识点归类、难度评估，记录解析结果 |
| 相似题推荐管理 | 同用户内知识点/难度规则优先，同科目 Embedding 检索补充，最多 5 题 |
| 变式题管理 | AI 基于原题同步生成并保存 3 道变式练习 |
| 复习计划管理 | 按第 1、2、4、7、15 天固定节点生成计划并发送站内提醒 |
| 练习记录管理 | 记录错题/变式题作答，答对 +15、答错 -20 更新原题掌握度 |
| 学情报告管理 | 请求时聚合当前周报：薄弱知识点、当前掌握度、周内新增和练习统计 |
| 错题本导出管理 | 按科目/知识点筛选导出 XLSX |
| 消息通知管理 | 复习提醒、AI 分析完成、周报查看提示 |
| 公告管理 | 管理员发布系统公告 |

### 3、拟定数据库方案（10 张物理表）

`user`（用户）/ `subject`（科目）/ `knowledge_point`（知识点）/ `question`（错题）/ `ai_analysis`（AI 解析记录）/ `variant_question`（变式题）/ `review_plan`（复习计划）/ `practice_record`（练习记录）/ `message`（消息）/ `announcement`（公告）

业务流程闭环：录入错题 → AI 解析归类 → 推荐相似题/生成变式题 → 生成复习计划 → 练习反馈更新掌握度 → 学情报告。
