## 六、需要学生理解的重点

1. 三个泳道回答“谁负责”：学生核对、自评；平台编排、检索和存数据；GLM辅助识别与生成，不能直接写数据库。
2. 图片识别只是候选，核对后才保存。识别出的学生作答不等于正确答案，识别失败仍可手录。
3. 保存错题就建固定复习计划，AI随后独立运行。AI失败不删除已保存数据，缺Key也不能用Mock冒充。
4. 相似题是检索已有个人题，变式题是模型新生成。练习由学生自评，掌握度只是有界规则分值，不是概率，也不驱动推荐排序。
5. 做练习和确认复习完成是两步，日期不自适应调整。教师只看系统汇总，不存在班级或个人钻取。
6. 导师讲需求分析是在帮助理解项目；已有开发和完整论文不回退，开题报告不重改。本轮Mock通过也不等于真实GLM已经重新实测。
