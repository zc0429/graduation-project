## 二、硬性指标（红线）

- **总字数 > 12000 字**（不含附录，含文献综述）；**查重率 < 20%**
- 绪论 ≥ 800 字；文献综述 2000–3000 字；论文主体 ≥ 8000 字（设计正文 ≥ 5000 字）
- **参考文献 ≥ 20 篇，其中近 3 年 ≥ 15 篇、外文 ≥ 2 篇**；正文引用须有角标且可跳转
- 文献综述约 10 篇评述，含中英文文献
- 附加材料：图纸、设计稿、光盘等作品证明；终稿含任务书、开题报告等，装订成册 + 刻盘

## 三、论文结构（14 个部分）

封面 → 目录 → 摘要（中英文）→ 绪论 → 文献综述 → 相关技术介绍（可选）→ 系统分析 → 系统概要设计 → 系统详细设计 → 系统实现与测试 → 总结 → 参考文献 → 致谢 → 附录（可选）

必须覆盖的软件工程过程：问题描述、可行性研究、需求获取、需求分析、概要设计、详细设计（数据库设计、UI 设计、数据访问层设计含类库设计）、编码实现（前后端代码结构 + 部分核心代码）、系统测试（单元测试、集成测试）、软件项目管理（进度安排、甘特图）。

排版要点：理工科标题编号 `1 / 1.1 / 1.1.1`；图表分章编号（图 2.5、表 3.1）；三线表；A4，左边距 2.75cm、其余 2.5cm；正文小四宋体、行距固定值 20 磅；目录自动生成且可点击导航；**标题文字必须与系统中的标题完全一致**（每版必查）。

## 四、系统开发要求

- **数据库**：除用户表等基本信息表外至少 5–6 张业务表，**总计约 7–8 张表**
- **业务深度**：不能只是对表的增删改查，要有业务流程和逻辑关联（如：申请→审核→流转→反馈的闭环）
- **规模**：页面数量随表内容相应增加

## 五、选题要求（重要）

1. 题目体现**所用技术 + 系统操作端 + 业务主题**，总字数 ≤ 25 字
2. 难度达到本科毕业水平，具有创新性、实用性
3. **基本都要与 AI 有关，但不是简单调用**（需要有 AI 与业务逻辑的深度融合）
4. 禁区（不能选）：❌ 网上购物商城类 ❌ 图书管理系统类 ❌ 二手商品商城类

## 六、选题推荐（4 个候选，按推荐度排序）

### ⭐ 当前选题（原候选 1）：AI 智能错题分析与学习推荐系统

- **正式题目（2026-08-23 更新）**：基于智谱GLM模型的AI错题分析与学习推荐系统设计与实现（是否符合学校“总字数 ≤25 字”的统计口径，待导师或论文系统确认）
- **业务闭环**：学生录入错题（文本/拍照 OCR）→ AI 自动归类知识点并生成解析与变式题 → 系统按遗忘曲线生成复习计划 → 学情周报可视化
- **AI 深度**（规避"简单调用"）：RAG（本地题库检索增强生成解析，防幻觉）＋ Embedding 相似题推荐 ＋ 知识点自动分类
- **表设计（8 张）**：user / subject / knowledge_point / question / ai_analysis / variant_question / review_plan / practice_record（2026-07-26 起与开题报告、毕业论文一致）
- **优势**：用户群就是在校学生，需求调研与测试方便；业务流程清晰，AI 融合点充分，答辩好讲
- **难点**：AI 输出的结构化控制（可用 JSON Schema 约束）；OCR 可用现成云服务或省略为手动录入

### 候选 2：AI 简历分析与岗位推荐系统

- **拟定题目**：基于 Spring Boot+Vue 的 AI 简历分析与岗位推荐系统
- **业务闭环**：上传简历 → AI 结构化解析 → 岗位匹配度评分（向量相似度+规则）→ AI 生成优化建议与模拟面试题
- **表设计（7 张）**：user / resume / job / parse_result / match_record / suggestion / interview_qa
- **优势**：贴近就业场景，新颖实用
- **难点**：PDF/Word 简历文件解析较繁琐；岗位数据来源需构造

### 候选 3：AI 心理健康陪伴与预警系统

- **拟定题目**：基于 Spring Boot+Vue 的 AI 心理陪伴与情绪预警系统
- **业务闭环**：情绪日记 → AI 情感打分 → 情绪趋势可视化 → 触发预警规则通知心理老师 → AI 树洞对话疏导
- **表设计（8 张）**：user / mood_diary / emotion_score / warning_rule / warning_record / consult_record / article / message
- **优势**：情感分析+规则引擎双 AI 融合点，社会意义强
- **难点**：题材敏感，论文表述需谨慎；预警逻辑需设计得当

### 候选 4：AI 智能菜谱与营养管理系统

- **拟定题目**：基于 Spring Boot+Vue 的 AI 菜谱推荐与营养管理系统
- **业务闭环**：录入现有食材 → AI 推荐菜谱 → 营养成分分析 → 生成一周膳食计划与采购清单
- **表设计（8 张）**：user / ingredient / recipe / nutrition / diet_plan / shopping_list / favorite / health_profile
- **优势**：业务生活化，数据好构造
- **难点**：AI 融合深度相对弱，需强化推荐算法部分以免被认定"简单调用"

## 七、开题报告格式要点（从范例提炼，同为胡韬老师指导）

- 结构：① 选题背景和意义（背景+意义两段，机打 ≥500 字）② 文献综述（前言→国外研究现状→国内研究现状→总结，逐篇角标评述）③ 研究内容（拟解决的问题 + 系统功能清单，范例列了 15 个功能）④ 研究方法、研究思路（研究方法/研究步骤/所需条件三段）⑤ 研究工作进展计划（须与任务书一致）⑥ 主要参考文献（≥15 篇，外文 ≥2 篇）
- 文献综述写法：每篇文献一两句话概括观点 + 角标 [n]；"述"的同时要有"评"（指出不足 + 自己的改进思路）
- 范例功能清单粒度参考：用户管理、XX 管理……约 12–15 项
