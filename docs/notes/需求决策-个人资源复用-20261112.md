## 暂定，待导师最终确认

| 决策 | 默认规则及理由 | 验证 |
|---|---|---|
| 归属范围 | 学生本人原题与其关联资源，不跨学生共享；教师/管理员无学习写入权 | 非本人、其他角色拒绝；他人练习记录不改变本人状态 |
| 知识复用 | 每原题一条当前内容，以科目、题干、答案、知识点及名称摘要匹配；有效缓存优先于模型配置检查 | 缓存复用、缺少模型配置仍可命中、编辑清理、来源修改保留 |
| 未练判定 | 当前学生对目标尚无practice_record；答错也算已练，获取或阅读不算 | 原题优先、返回不标记、错误作答消耗、耗尽后补充 |
| 顺序与重做 | 原题优先，变式按ID升序；显式重做不改变题池身份，写一条新作答记录 | 两次重做、继续重新查询、前端只提交一种目标 |
| 生成与失败 | 沿用原接口每批3题；全部校验后事务保存，规范化题干完全重复拒绝；失败保留旧资源 | 格式/空内容/重复/过期快照拒绝，整批回滚，失败可重做 |
| 并发 | 单服务实例以64个分段可重入锁串行同一原题；模型调用不持有数据库事务，短事务锁原题复查 | 并发知识请求只调用一次；写入前再次查可用结果 |

不承诺跨实例只调用一次模型、语义去重、自动批改、跨学生题库、班级管理或概率知识追踪。复习完成仍须独立确认；不改变现有五阶段安排和掌握度分值。固定批量属于沿用接口合同，不是新设导师业务参数，不放入业务图。
