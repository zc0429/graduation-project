# 需求分析与业务流程讲解提纲

用于和导师交流需求分析。保留现有系统、测试和完整论文；导师目前讲需求分析是帮助理解设计依据，不代表项目重新开始，也不再修改已通过的开题报告。

## 1 为什么选这个课题

错题常分散在试卷和截图里，记下以后还会遇到“不知道错在哪里、不知道练什么、忘了复习”。本课题把整理、辅助分析、练习、按期复习和学习反馈连起来，超过一个只做增删改查的错题本。没有长期实验，不能说已经证明能提高成绩。

## 2 系统解决什么问题

按科目、知识点整理个人错题；用图片候选减少输入工作，富文本保留层次与上下标；GLM辅助解释；提供本人旧题或新变式用于练习；固定任务提醒再看；用记录和报告帮助自查。没有实施问卷或访谈，不编造调研人数和比例。

## 3 三类角色负责什么

| 角色 | 职责 | 边界 |
|---|---|---|
| 学生 | 录入、核对、查看解析、选择练习、自评、确认复习、个人报告 | 自评不等于AI或教师批改 |
| 教师 | 查看系统聚合报告、消息公告、本人资料 | 无班级绑定、学生个人钻取和逐题批改 |
| 管理员 | 查询/停用账号，维护科目和两级知识点，发布公告 | 无任意角色分配、恢复账号、删科目、编辑或下线公告等未实现入口 |

## 4 模块及其作用

账号权限确定谁能看什么；科目和知识点提供分类；错题管理保存题干、答案与题图；AI分析提供辅助说明；相似题和变式提供两类资源；练习记录保存自评；复习计划安排时间；报告和消息反馈已有数据；导出便于离线整理，公告用于公共通知。

## 5 一道错题从录入到复习

学生手录，或上传单题图片获取候选。核对科目、题干和来源后保存。平台过滤和校验，保存错题及图片，同时建立第1、2、4、7、15天计划，再独立触发解析。

平台将富文本转成纯文本，生成向量，在本人同科目题库检索参考题，把题干、可选答案、候选知识点和参考片段交给GLM。平台校验模型结果后展示；失败不丢原题和计划，学生可重试或继续学习。

学生重做原题、选择已有相似题或请求3道新变式。作答后对照答案自评，正确加15、错误减20，限制在0—100。到期后查看复习任务，复习完另行点击完成。提交练习不会自动完成复习，也不会调整日期。

## 6 平台与AI服务怎么分工

平台管业务和数据：鉴权、过滤、保存、检索范围、排序、提示词、状态、计划、记录与统计。AI服务提供模型能力：GLM负责看图提取、辅助归类、错因/解题解析和变式生成，Embedding服务另生成题干向量。模型输出经过平台校验；AI不能直接连数据库写记录。

## 7 为什么需要三个泳道

学生决定输入和自评，平台管流程与数据，AI提供外部识别与生成。三个泳道能回答“这个动作是谁做的”，也能解释AI失败为何不丢错题。复习和管理没有必须调用AI的动作，不强加AI泳道。

## 8 判断分支为什么存在

图片或手录适应不同题源；候选确认防止看图看错，校验失败返回修改；拓展练习不是必做步骤；相似题检索和变式生成是不同请求；无可用题允许回原题；无复习任务可以结束查看；学生是否确认决定该条任务是否完成。

分析成功和失败通过状态与提示说明，没有把每种网络错误都变成菱形，以免主图难读。失败后重试是学生选择，已保存数据保留。

## 9 非功能需求

安全：角色权限、学生数据隔离、私有题图、密钥不入库，富文本前后端过滤防XSS。可靠：保存和分析分开，旧异步任务不覆盖新编辑，失败明确提示。可用：加载、空状态、失败反馈可见，适配常见屏幕。性能：解析异步、页面轮询，没有压力测试就不承诺固定并发量和毫秒数。可维护：分层服务、可配置模型、可复跑测试和可编辑图源。

## 10 明确不支持什么

无班级/课程/任课关系管理、教师逐题批改、学生个人钻取、整卷拆题、AI自动判分、自动学习路径、BKT/DKT训练、按遗忘概率自动改期或掌握度驱动的推荐排序。富文本不是公式排版系统，不提供LaTeX公式编辑、任意HTML、外链或题干内嵌图片；题图通过独立附件上传。

## 11 导师常见问题与回答

| 问题 | 简洁回答 |
|---|---|
| AI体现在哪里，为什么不是单纯调接口？ | 围绕错题组织候选知识点、个人题库检索、校验、异步状态和学习闭环；没有训练自己的大模型，也不夸大算法创新。 |
| 为什么检索参考题？ | 给模型补充本人相关旧题并保留参考ID，但不保证模型一定正确。 |
| 能准确判断真实错因吗？ | 只能依据题干、答案和参考题辅助说明，没有独立保存完整解题过程，不能说精准还原真实错误。 |
| 图片识别后立即入库吗？ | 不会，先回填候选，核对再保存。学生作答不自动写成标准答案。 |
| 富文本会不会带来脚本？ | 浏览器DOMPurify、后端Jsoup白名单，展示也过滤；AI和Excel接收规范化纯文本。 |
| AI失败怎么办？ | 保留错题和计划，允许重试；缺密钥明确提示，不偷偷用Mock冒充。 |
| 相似题和变式题一样吗？ | 相似题是本人已有题，变式是GLM生成，平台验证3题完整合格后保存。 |
| 谁批改练习？ | 当前由学生对照答案自评，系统没有自动批改。 |
| 掌握度是不是掌握概率？ | 不是，是正确加15、错误减20的题目级规则分值，不决定相似题排序。 |
| 复习日期会自动改变吗？ | 不会，固定五个节点；练习和确认完成是两个操作。 |
| 教师能看哪个学生？ | 当前只看系统聚合，不能钻取个人或班级。 |
| 新默认模型这次实测了吗？ | 配置、离线请求和缺密钥行为已测；本轮无真实密钥，文本及图片联网仍待测。历史证据按原日期保留。 |
| 现在讲需求分析，做好的代码怎么办？ | 保留并继续完善，用真实实现检查需求是否讲清楚，不把进度退回起点。 |
