# 字体环境排查与验证范围

## 已确认的执行规范

论文题目三号黑体18pt、加粗居中；章标题四号黑体14pt；节和条标题小四黑体12pt；中文正文小四宋体12pt；正文数字及字母小四Times New Roman 12pt；页码小五宋体9pt。A4及学校统一封面保留；图表、目录、摘要、参考文献的专用字号和行距继续按学校原模板执行。核心代码按正文小四及固定20磅排版，字体随字符使用宋体与Times New Roman。

本轮不再将字体规范列为待确认问题。需要区分DOCX中指定了字体、机器实际安装了字体、PDF实际使用了字体，以及Microsoft Word实际排版四个层次。

## 实际排查与合法安装

1. 检查Fontconfig字体目录、匹配结果、可用排版程序及挂载位置。起始环境无宋体/黑体/Times New Roman原字体，Times New Roman匹配为Liberation Serif；原导出配置还强制指定三种替代字体。`fc-match`退出成功并不代表请求的原字体存在。
2. 读取微软官方[SimSun](https://learn.microsoft.com/en-us/typography/font-list/simsun)、[SimHei](https://learn.microsoft.com/en-us/typography/font-list/simhei)、[Times New Roman](https://learn.microsoft.com/en-us/typography/font-list/times-new-roman)及[字体许可FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)。相关字体随指定产品分发，普通Windows字体许可不能直接视为向任意其他计算机或服务器复制的授权。页面摘录保存在`font-sources.txt`。
3. 从[Microsoft Core Fonts既有分发项目](https://downloads.sourceforge.net/corefonts/times32.exe)取得Times New Roman原分发包，读取[Core Fonts EULA](https://corefonts.sourceforge.net/eula.htm)。其“Installation and Use”允许安装使用；“Restrictions on Alteration”允许文档嵌入时子集化。未修改字体名称或内容，也不将字体文件提交仓库。
4. 解包常规、粗体、斜体和粗斜体四个文件，逐一与[Debian msttcorefonts官方源码](https://sources.debian.org/data/contrib/m/msttcorefonts/3.8.1/update-ms-fonts)列出的SHA-256核对，全部一致。字体内部名称为Times New Roman、版本2.82，OS/2 `fsType=0`。记录见`times-new-roman-installation.json`。这是实际原字体的较早版本，不能推断其与任意Windows/Office所带版本的分页完全相同。
5. 字体安装在用户字体目录，刷新Fontconfig，并只读挂载给本次LibreOffice容器。容器实际匹配常规和粗体到Times.TTF、Timesbd.TTF；PDF的字体清单及字形span分别验证实际使用，而非只检查字体声明。
6. 宋体和黑体仍未发现本环境可验证授权的安装包。字体官方网站提供产品与许可信息，不构成此云端环境的字体使用授权。因此本轮解决了Times New Roman，未将Noto或其他字体改名冒充SimSun/SimHei。

安装过程、内部字体名称与哈希、渲染容器匹配和最终PDF字体分别保存在`font-extraction.log`、`times-new-roman-installation.json`、`render-environment-fonts.log`及`pdf-fonts.txt`。解包工具运行于可重建容器，字体与授权文本仅安装到本机用户目录，不改系统业务或学校原件。

## 导出行为修正

正式导出默认使用`fonts-original.conf`，通过字体内部名称而不是“能匹配到某个字体”来判断。缺少任何原字体时退出码为2，已实际执行并保留`formal-export-blocked.log`。

转换先写入临时目录，随后检查实际渲染PDF的字体清单，再发布到交付目录，结果见`pdf-font-render-check.json`。这样即使宿主装有字体而容器未挂载，也不会把容器替代字体PDF当作原字体成品。受限预览转换不会临时覆盖已有正式PDF。

仅在显式设置`THESIS_ALLOW_SUBSTITUTE_PREVIEW=1`时使用预览配置，且优先选择已安装原字体。导出文件改名为`毕业论文-字体受限预览.pdf`。更新页码、文档验证及渲染脚本使用同一预览文件，避免把旧正式文件当作本轮结果。最终报告保留`original_fonts_verified=false`及`microsoft_word_verified=false`，没有以替代字体结果宣称学校原字体全部通过。
