## 技术描述与31处核心代码

实际后端JDK21、Spring Boot3.5.16、MyBatis-Plus3.5.17、MySQL8；前端Vue3.5.41、Element Plus2.14.4、Vue Router5.2.0、Pinia4.0.3、Vite8.2.1、TypeScript6.0.3、Axios1.19.0、ECharts6.1.0（依赖以锁文件为准）。BCrypt只引用security-crypto，鉴权是自建JWT拦截器，不能写成Spring Security完整过滤链。没有Redis、向量数据库、模型训练或概率知识追踪。

正式生成由GLM大模型HTTP客户端封装，向量服务在真实链路要求1024维有限数。MockLlmClient的8维伪向量只用于工程替身；本轮实际Mock验证不证明真实1024维链路新验收。RAG本人同科目、排除源题、内存余弦>0取前三；推荐同知识点按难度差优先，再向量补足至五条，不读mastery/练习历史。缓存输入摘要包括题目/用户/科目/知识点及其名称/题干/答案，命中先于模型就绪检查。64个分段锁只串行同实例；短事务再次核对快照/资源，不是分布式只生成一次。

全部31段、275原始行重新逐行匹配当前实际源码及SHA-256；未发现伪代码、内容重复堆砌或过时片段。原PR #7的清单原样保留，本轮清单独立存[code-excerpts.json](code-excerpts.json)。7.5同步实际科目校验和固定日期注释，7.6因新增校验行顺延；其余文件路径/源码片段不改。
