# 真实 GLM 浏览器业务 E2E 与论文截图记录

## 1. 验证范围

- 验证日期：2026-08-26
- 工作分支：`codex/real-ai-e2e-evidence`
- Chat provider / model：智谱 `glm-4.7-flash`
- Embedding model：智谱 `embedding-3`
- Embedding 维度：1024
- 浏览器：Playwright Chromium
- 统一视口：1600 × 1200，截图使用同一桌面视口的完整页面
- 演示账号：独立正式证据学生，不属于 Mock fixture

本轮目标是验证真实模型参与的浏览器核心业务闭环并生成论文候选截图，不是 RAG 效果 benchmark，也不扩展为权限、HTTP 状态码或论文主体整改。旧的 Mock 设计截图只证明界面与交互开发完成，本目录的新截图才用于证明本轮真实智谱模型运行结果。

## 2. 执行路径

正式证据链依次完成：

1. 登录独立演示学生账号。
2. 准备一条同账号、同科目、同知识点的真实向量参考题。
3. 从浏览器填写并保存一条二次函数错题。
4. 触发真实 `glm-4.7-flash` 异步分析并等待成功。
5. 查看知识点、难度、中文错因、中文解析和 RAG 引用。
6. 打开同账号相似题入口并验证候选归属。
7. 调用真实 GLM 生成 3 道变式题，并从数据库回读。
8. 完成一次正确练习，验证练习记录和掌握度更新。
9. 查看复习计划、学生学情报告、教师实际报告页和管理员实际用户页。

真实调用轮因智谱接口限流出现过 HTTP 429，客户端仅按既有有限重试与 15 秒退避处理，最终分析和变式生成均成功。首次完整链路已经执行到最后一个管理员页面，但测试因用户名在页面出现两处而触发 Playwright strict locator 错误；最小修正定位后，使用同一套刚生成的正式证据数据进行无重复模型调用复跑，结果为 `1/1 passed`。测试默认仍会重新调用真实模型；`REAL_AI_E2E_REUSE=true` 仅用于本次定位修复后的证据复核。

## 4. RAG、相似题与数据隔离

- 目标题 ID：225；RAG `referenceIds = [223]`。
- 正式 `RagService` 的候选筛选规则是“同用户 + 同科目”，不强制同知识点。本轮参考题与目标题恰好都属于“二次函数”，这是测试数据现象，不应在论文中描述成 RAG 的强制知识点过滤条件。
- 参考题向量同样为 1024 维；结果排除了目标题自身。
- 浏览器 RAG 页只展示后端返回的真实参考 ID，不伪造参考正文或文献入口。
- 相似题返回题目 223，候选不包含原题，且全部属于当前学生。

相似题入口本轮做了最小恢复。恢复依据是 `RecommendServiceImpl` 和 `RagServiceImpl` 已在查询层按原题所属 `userId` 限制候选，并保留结果层 ownership guard；既有后端隔离测试覆盖学生、管理员代查与补足路径，本轮又增加前端懒加载回归。正式推荐采用混合策略：同知识点、相近难度候选优先，不足时再用 `RagService` 的语义向量结果补足。入口只在用户打开“相似题”标签时请求，加载失败、空结果与重试均有真实状态展示。本轮题目 223 可能由同知识点/难度优先路径命中，因此 `07-similar-questions.png` 不得单独作为纯向量推荐或余弦相似度排序效果证据；本轮真正的真实向量检索证据仍是 `06-rag-references.png`。

## 8. Opt-in 与默认安全性

真实 E2E 与 Mock smoke 使用独立 Playwright 配置。默认命令不会调用 GLM；只有显式设置开关并注入本地密码时才执行：

```powershell
$env:RUN_REAL_AI_E2E = 'true'
$env:REAL_AI_E2E_PASSWORD = Read-Host '正式证据学生密码' -MaskInput
$env:REAL_AI_E2E_SEED_PASSWORD = Read-Host '本地种子角色密码' -MaskInput
npm run e2e:real-ai
```

未设置 `RUN_REAL_AI_E2E=true` 时，真实用例为 `1 skipped`，不启动真实证据前端服务、不连接后端，也不发起模型请求。安全运行摘要只写入已忽略的 `web/test-results/real-ai/summary.json`。

## 9. 数据保留与安全清理

- 保留：独立正式证据学生、参考题、目标题、真实分析、1024 维向量、3 道变式、1 条练习记录和复习计划，供论文后续演示复用；这些数据带专用 source，不属于普通 fixture。
