- AiAnalysisServiceImpl：校验结构化结果并保存解析/状态；模型不是直接面向学生的数据输出通道。
- VariantServiceImpl.generate第42行起：每次请求生成并校验、追加存库；list第87行起读取已有变式。没有生成前未做题耗尽判断。QuestionDetailView.vue已有loadVariants，不能将“读取复用已有变式”全部误判为未实现。
