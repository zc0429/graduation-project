# 业务流程图与导师介绍讲稿

2026-11-01。配合 [三页业务流程图](business-flow/业务流程图.drawio) 使用。以下依据本项目当前实现说明；其中数学题是讲解用的假设例子，不是本轮模型实测结果。

## 一、开场先说清楚要解决什么

老师，我这个系统主要解决三个问题：错题记下以后，不清楚怎么分析；看完解析以后，不知道接着练什么；当时会了，过几天又忘记复习。因此，我把错题录入、辅助解析、练习、按期复习和学习反馈连成一个过程。

## 二、图应该怎么看

这次参考《参考论文1》第3.3节的业务流程表达，主要对应图3.1、图3.2，也就是PDF第19、20页。采用纵向分栏、矩形动作框、圆角开始结束框、菱形判断和直角箭头。参考文件部分区域渲染成黑块，本次只借鉴能够确认的画法。

读图时先看栏名，再从“开始”沿箭头走。框放在哪一栏，就表示这一步由谁负责。箭头跨过栏线，表示双方发生交接，例如学生提交题目、平台请求AI分析。不是一口气把左栏读完，再读中栏和右栏。

白色框统一表示动作。本项目没有线下采购、配送等业务，不沿用参考论文中表示线下任务的灰色底纹。“图片”“仅新变式”等标注表示在对应条件下才走这条线，不代表每一道题都必须调用所有AI能力。箭头描述业务交接，具体网络请求的等待、轮询与数据库事务在详细设计中展开。

## 三、三分钟讲解稿

### 第一张：一道错题怎样变成可以继续学习的材料

老师，这张图分为学生、学习平台和AI服务三栏。学生负责输入、核对和学习；平台负责检查、保存、检索和记录；AI提供识别、分析和生成能力。

首先，学生可以直接输入一道错题，也可以上传单题图片。如果上传图片，平台先检查图片，再让GLM识别，返回的内容只作为候选。学生要先检查题干、科目等有没有识别错，修改后再提交；识别失败也可以手工输入。手工输入这条线直接进入核对环节，不需要先调用图片识别。

其次，校验通过后，平台先把错题保存下来，同时安排五次复习，再独立启动后台分析。分析前会从这名学生自己的相关错题中查找参考内容，然后把本题、候选知识点和参考内容一起交给GLM，让它辅助归类、说明可能的错因并给出解题解析。返回后由平台检查和保存结果。即使AI失败，原题和复习计划也还在，可以重试或继续使用其他功能。

然后，学生可以选择是否现在练习。想巩固原题，就重做原题；想练以前做过的相关题，就查看本人题库里的相似题；想练新题，就请求GLM生成三道变式，由平台检查合格后保存。相似题和新变式是两种来源，不会把已有题都说成AI现场生成。没有可用拓展题时，也可以继续练原题。

最后，学生作答后对照答案，自行判断对错。平台保存这次记录并更新对应原题的掌握度，再提供学习反馈。学生也可以先不练习，直接查看已有反馈。

### 第二张：过几天怎么把这道题再捡起来

第二张单独讲复习。计划在保存错题时就建立，时间是第1、2、4、7、15天，不用等AI分析成功。

学生通过提醒或任务列表，查看到期、逾期且尚未完成的任务。有任务就选择错题复习，也可以按需练习。复习以后，必须另外点击确认完成，平台才把这一条计划标记为已完成。不确认就保留，下次还能处理；没有任务就结束本次查看。

这里要区分两个动作：提交练习，是记录“我这次做得怎么样”；确认复习完成，是记录“我处理了这条复习任务”。它们不会自动代替对方，日期也不会随着答对或答错自动重排。每天早上8点发送当日待复习提醒，提醒本身不代表任务完成。

### 第三张：管理员和教师各自做什么

第三张包含两段独立业务。管理员维护科目和知识点、查询或停用账号、按需发布公告，平台检查并保存操作；教师请求学情报告，平台根据当前记录汇总系统的错题、练习、复习和掌握度情况。

这两段业务不需要每次学习都依次经过。当前教师看到的是系统汇总，尚不支持班级管理、查看指定学生明细或逐题批改。

## 四、用一道题解释几个术语

假设学生录入“解方程 x²－5x＋6＝0”，这是为了帮助理解流程的例子。

| 术语 | 可以怎么向导师解释 | 本项目中的对应做法 |
|---|---|---|
| 图片识题 | 先替学生抄题，抄完由学生检查 | 单题图片返回候选，不直接作为正式错题保存 |
| 知识点归类 | 给错题贴一个合适的分类标签 | 模型从平台提供的候选知识点中选择，平台验证结果 |
| 文本向量 | 把题目转换成一组便于比较的数字 | Embedding服务生成1024维向量，用来比较题意接近程度 |
| RAG（检索增强生成） | 像答题前先翻自己的相关笔记，再结合笔记作答 | 从本人同科目旧题中检索最多3道参考题，再组织分析输入；没有可用参考时不虚构旧题 |
| 相似题 | 以前存过的同类题 | 推荐优先考虑同知识点和相近难度，再用向量结果补足，最多5道；具体范围以服务端查询和归属校验为准 |
| 变式题 | 换一些条件，再练同一类方法的新题 | 请求模型生成3道，平台验证完整合格后保存 |
| 掌握度 | 这道题的练习记分牌 | 自评正确加15、错误减20，限制在0—100；不是“真实掌握概率” |
| 学情报告 | 把已经留下的学习记录汇总出来 | 根据已有错题、练习和复习记录统计，没有长期实验就不宣称提高了成绩 |

例如，题库里如果已存在相关方程题，系统可以把它作为参考或相似题；新变式则可以是保留同类解法、改变条件的新题。新生成题的正确性仍需检查，不能因为来自大模型就视为标准答案绝对正确。

练习更新要说准确：重做某道相似题，更新的是实际练习的那道题；做某道变式，更新的是该变式关联的原题。不会因为题目是从A题推荐过去的，就把所有结果都累计给A题。

## 五、导师追问时怎么回答

| 导师可能问 | 建议回答 |
|---|---|
| 你的系统为什么不只是一个错题管理表？ | 保存后还接了辅助分析、相关题获取、自评记录、复习任务和报告，形成后续学习过程。 |
| AI具体负责什么？ | GLM负责图片内容提取、辅助知识点归类与解析、变式生成。向量服务另提供向量，检索和业务控制由平台完成。 |
| 是不是训练了自己的大模型？ | 没有训练自己的大模型，主要工作是模型接入、个人题库检索、输入组织、输出校验以及学习业务整合。 |
| RAG就是联网搜索吗？ | 本项目检索的是本人相关旧题，不是让模型上网搜索，也没有接入一个外部公共题库。 |
| 能确定学生真正错在哪里吗？ | 只能基于现有题干、可选答案与参考材料给辅助说明，不能把它说成对学生思维过程的准确诊断。 |
| 谁批改，系统怎么知道对错？ | 当前由学生对照答案自评，再提交正误结果；不是AI自动判分或教师在线批改。 |
| 个性化和知识追踪体现在哪？ | 候选材料来自本人题库，保留个人练习记录并维护题目级规则分值。没有训练概率知识追踪模型，也没有按分值自动生成学习路径。 |
| 复习时间是AI决定的吗？ | 是固定规则安排的五个节点，不是模型预测遗忘概率后动态安排。 |
| AI断网、失败会怎样？ | 图片识别失败可手录；分析失败保留原题和计划并明确提示；新变式失败不冒充成功结果。 |
| 新默认模型是否都实测通过？ | 本轮只重绘和复核代码口径，没有执行新的真实模型联网验证；历史验证和当前待测项分开说明。 |
