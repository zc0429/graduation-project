## 角色与业务场景走查

| 场景 | 路径检查结论 |
|---|---|
| 手工录入成功 | 输入→提交→平台保存错题/计划→解析→平台结果→学生查看，可结束或转图3.3 |
| 图片辅助成功/失败 | 平台检查→模型→平台处理→录入；不可识别直接由平台提示手录，仍须有效输入后提交 |
| 保存失败/分析未启动/分析失败 | 保存失败回输入；分析未启动或失败不撤销原题/计划，失败反馈可重试或退出 |
| 学习已有内容/生成新内容 | 先查知识内容，有则直接读；无则生成、校验入库后读；均可继续选择与再次查库 |
| 练习未练题/资源耗尽 | 先查本人可用题并优先未练；耗尽再生成；作答自评后保存题目标识和掌握度，循环后重新查库 |
| 无效生成/生成失败 | 平台“结果可用？”否→B，平台提示后到继续/退出，不写成功内容、不虚构作答 |
| 纯阅读/实际作答 | 纯阅读跳过练习记录；实际作答必经记录与掌握度处理，再判断是否完成复习 |
| 有/无复习任务、确认/不确认 | 无任务可退出或选择普通学习；仅选定任务且确认才完成该条任务，否则保留状态；不自动改期 |
| 管理员查询/变更/失败 | 所选事项→平台权限/查询或保存→本人收到结果/失败提示→结束，不进入教师业务 |
| 教师有数据/无数据/失败 | 请求→平台按当前记录聚合→教师查看报告/提示→结束，不依赖管理员本次操作 |

本稿可作为导师审阅与A4打印的数字候选稿。知识学习缓存、自动未练筛选和耗尽后生成仍是后续实现目标；导师业务确认、实体打印、交互式GUI编辑保存及正式论文替换均不得误记为本轮已完成。
