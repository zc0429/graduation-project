# 毕业论文与提交文档（Markdown 源稿 → 按需导出 DOCX/PDF）

本目录用于存放毕业论文及需提交导师的文档。**正文统一以 Markdown 撰写**，后续按需整理为可交付的 DOCX 或 PDF；格式和节点优先遵循 `docs/materials/27届毕业设计学校通知和模板/` 中的 2027 届最新通知、规范与对应模板。

## 现有文件

- `毕业论文.md` — **现行第1—9章正式论文源稿**（PR #5集成候选），与11表88字段、39个映射、32篇参考文献一致；对应最新DOCX/PDF见[论文交付索引](thesis-audit-20261112/README.md)，2026-11-13母版预排版90页；原宋体、黑体、Times New Roman仍需实机复核
- `任务书-AI错题分析与学习推荐系统.md` — 毕业设计任务书 Markdown 源稿，按任务下达阶段的目标、要求与预期成果表述，不写后验实现状态
- `开题报告.md` — 开题报告 Markdown 主源稿，按开题阶段的设计方案与实施计划表述；10 张物理表属于拟定数据库方案，不写成完成态事实
- `第6章与第7章大纲.md` — 系统实现、测试、Gate5 状态、限制与总结的证据化写作提纲
- `screenshots/real-glm/` — 真实智谱浏览器闭环生成的 12 张论文候选截图；根目录的 14 张旧图属于 Mock 页面走查证据

## 写作约定

- **正文一律 Markdown**，导出 DOCX/PDF 时再套用 2027 届最新规范与对应模板；论文正文采用中文宋体小四、数字/英文 Times New Roman 小四、固定值 20 磅、首行缩进 2 字符及学校规定页边距，开题报告优先复刻 2027 届开题表格的实际版式
- 命名建议：源稿 `任务书-XXX.md`；导出件 `任务书-XXX.docx`、`毕业论文-v0.1-初稿.docx` 等，保留关键版本
- 导出件可纳入 Git 管理，每次阶段性修改后提交一次
- 正式论文现行参考文献**32篇**（原[1]—[20]保留序号并校正两处题录，[21]—[32]新增），请以[参考文献核验](../references/README.md)为准；已通过开题报告仍保持其形成时的20篇文献与10表拟定方案，严禁倒灌终稿状态
- 材料表述必须符合形成阶段：任务书写任务要求，开题报告写拟定方案与后续验证计划，中期材料写阶段进展，最终论文再以代码、`server/src/main/resources/db/schema.sql`、控制器映射与 `docs/validation/` 为准描述真实实现与测试结果
- Gate5 自动指标与人工盲评分别报告；人工评分表未填写前不得宣称人工评审通过
- 开题报告正式导出遵循 `docs/materials/27届毕业设计学校通知和模板/附件3：毕业论文（设计）相关模板（2027）/附件3：毕业论文（设计）内容资料.docx` 的表格结构；选题背景与意义不少于 500 字，主要参考文献一般不少于 15 篇且外文不少于 2 篇，“指导教师意见”和“系意见”均留白待相应人员审核签字
- 正式开题报告的可编辑文件为 `output/docx/云南工商学院毕业设计开题报告-赵灿.docx`，提交文件为 `output/pdf/云南工商学院毕业设计开题报告-赵灿.pdf`；Markdown 始终作为内容主源稿保留
