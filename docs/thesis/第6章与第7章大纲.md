## 6 系统实现与测试

### 6.1 系统实现环境

#### 6.1.1 硬件与操作系统环境

- 说明 Windows 本地开发与验证环境，不虚构处理器、内存等尚未采集的硬件参数。
- 待正式成稿前补采：CPU 型号、内存容量、磁盘可用空间。

#### 6.1.2 后端开发环境

- JDK：Temurin 21.0.11。
- Spring Boot：3.5.16，版本固定不升级。
- 项目构建：仓库 Maven Wrapper 3.9.16，Windows 命令为 `mvnw.cmd`。
- 数据库：MySQL 8.0.40，数据库名 `wrongbook`，实际初始化 10 张业务表。
- 数据访问与鉴权：MyBatis-Plus 3.5.17、JWT、BCrypt。

#### 6.1.3 前端与自动化测试环境

- Vue 3、Vite 8.2.1、Element Plus、Pinia、Vue Router、ECharts。
- Playwright 1.62.1 与 Chromium，统一视口 1600×1200。
- 项目基线 Node.js 22.23.1 LTS；本次 Windows 实测使用 Node.js 25.5.0 并完成构建及走查，切换到基线版本后需补做回归记录。

#### 6.2.3 AI 解析与 RAG 推荐实现

- 说明 `LlmClient` 已同时具备离线 `MockLlmClient` 与真实 `OpenAiCompatibleLlmClient` 两条实现，可通过环境变量在 `mock`、`glm`、`deepseek` 间切换。
- 正式目标为智谱 `glm-4.7-flash` 文本生成与 `embedding-3` 语义向量（默认 1024 维）；当前尚无智谱密钥，因此不得把 GLM 的正确率、稳定性或成本写成已验证结论。
- DeepSeek `deepseek-v4-flash` 已完成 1 次 72 tokens 的最小联网 JSON 调用验证；DeepSeek 官方无 Embedding 接口，临时模式明确使用 `local-char-ngram-256-v1` 本地词法向量，不表述为真实语义 Embedding。
- 现有 14 张截图仍来自 Mock 演示数据，后续配置智谱密钥并重新生成向量后再重跑业务 E2E 与论文截图，不能用现有截图证明 GLM 效果。
- 说明本次自动化使用两条明确标注“自动化测试数据”的二次函数错题验证 RAG 引用关系，不将其作为真实教学效果数据。
- 关键代码选取：`AiAnalysisServiceImpl`、`EmbeddingServiceImpl`、`RagServiceImpl`、`OpenAiCompatibleLlmClient`、`MockLlmClient`。

### 6.4 系统业务流程实现

#### 6.4.1 错题分析闭环

- 错题录入 → 数据持久化 → 可配置模型网关解析 → 知识点归类 → RAG 参考检索 → 解析结果展示；截图证据仍需在智谱 GLM 正式配置后重新生成。

- 五阶段计划生成 → 到期复习 → 消息提醒 → 周报汇总 → 薄弱知识点反馈。

## 7 总结

### 7.1 主要工作总结

- 总结完成 Spring Boot 3.5.16 + Vue 的前后端分离系统，实现三角色权限与 10 表数据模型。
- 总结错题录入、可配置模型解析、RAG 参考、相似题/变式题、遗忘曲线计划和学情报告组成的业务闭环。
- 总结 Windows 环境、数据库初始化、构建测试、Playwright 走查和论文截图已经形成可复现证据链。

### 7.2 系统特点

- 将错题管理从单纯 CRUD 扩展为分析、推荐、复习和反馈闭环。
- 通过 `LlmClient` 接口隔离模型提供方，支持 Mock 离线演示、DeepSeek 临时联调以及智谱 GLM 正式接入。
- RAG 解析展示本地参考题关系，使解析来源比无依据生成更易追溯。
- 复习计划与掌握度、周报统计关联，体现个性化学习路径。

### 7.3 存在的不足

- 当前只有 DeepSeek 最小联网调用证据，智谱 GLM 与 Embedding-3 尚未完成正式联网测试，不能据此评价其正确率、稳定性与成本。
- 受控测试样本仅 2 条错题，不能代表真实学生群体、长期学习过程或教学效果。
- 教师端当前为全科目聚合视角，尚无班级—学生绑定和分层干预能力。
- 自动化测试覆盖核心页面，但修改、删除、导出、异常、越权、性能和兼容性测试仍需补充。
- 前端生产包存在大体积 chunk 警告，首屏加载和按需拆包仍有优化空间。

### 7.4 后续展望

- 在保持 `LlmClient` 边界不变的前提下接入真实模型，增加提示词版本、超时重试、内容安全和降级策略。
- 建立带人工标注的错题评测集，评价知识点分类、解析质量、相似题相关性和变式题正确性。
- 完善班级与课程关系、教师干预、长期掌握度追踪和更细粒度的知识追踪模型。
- 增加导出鉴权、接口自动化、性能和安全测试，并引入持续集成。
- 对 ECharts 和 Element Plus 进行按需加载与代码分包，降低生产包体积。
