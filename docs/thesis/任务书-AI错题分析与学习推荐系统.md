## 选题背景及目的

（导出时：左侧窄列竖排黑体标签"选题背景及目的" + vMerge 跨本节所有段落；右侧宽列正文，宋体小四、行距固定 20 磅、首行缩进 2 字符、两端对齐。）

随着信息技术的飞快发展和教育信息化的持续推进，个性化学习已成为教育领域的重要发展方向。在日常学习中，错题是反映学生知识薄弱环节的最直接载体，对错题进行科学整理与深度分析，有助于学生精准定位知识漏洞、提升学习效率。

然而，传统的错题整理方式普遍存在明显不足：学生手工摘抄错题费时费力，难以坚持；错因分析停留在表面，无法准确对应到具体知识点；复习计划依赖主观安排，缺乏科学的遗忘规律指导；同类题目难以举一反三，导致错题重复出错。现有错题类应用多停留在"拍照收藏"层面，缺少基于知识图谱的归类、基于大模型的解析以及基于遗忘曲线的复习推送的完整闭环。

因此，本课题拟设计并实现一个基于 Spring Boot+Vue 的 AI 错题分析与学习推荐系统。该系统通过 AI 自动完成错题的知识点归类与错因解析，借助检索增强生成（RAG）技术提升解析准确性；基于题目语义检索实现相似题与变式题推荐；依据艾宾浩斯遗忘曲线自动生成复习计划并推送提醒；并定期生成学情报告，帮助学生形成"录入—解析—推荐—复习—反馈"的个性化学习闭环。

### 一、研究目标

本次研究的目标是设计并实现一个基于 Spring Boot 和 Vue 技术的 AI 错题分析与学习推荐系统，具体实现包括以下几个方面：

- **用户管理功能**：实现用户的注册、登录、信息修改、注销账号等功能，支持学生、教师、管理员多角色权限管理。
- **科目管理功能**：用于维护系统涉及的学科信息，如数学、物理、英语等。
- **知识点管理功能**：用于维护一级章节与二级考点的两级知识点体系，为错题归类提供基础。
- **错题录入管理功能**：支持学生以文本或图片方式录入错题，维护错题的题干、答案、所属科目等信息。
- **AI 解析管理功能**：系统调用大语言模型，结合本地题库检索增强生成（RAG），自动完成错题的知识点归类、错因分析与解析生成，并标注所参考的本地题目来源。
- **相似题推荐管理功能**：基于题目语义向量检索，为学生推荐同知识点的相似题目，实现举一反三。
- **变式题管理功能**：基于原题由 AI 生成变式练习，帮助学生针对性巩固薄弱知识点。
- **复习计划管理功能**：依据艾宾浩斯遗忘曲线自动生成复习任务，并向学生推送复习提醒。
- **练习记录管理功能**：记录学生重做错题与完成变式练习的作答情况，动态更新各知识点掌握度。
- **学情报告管理功能**：定期生成学情周报，可视化展示薄弱知识点分布与掌握度变化趋势。
- **错题本导出管理功能**：支持按科目、知识点筛选导出错题本，便于线下打印复习。
- **消息通知管理功能**：用于系统向学生发送复习提醒、报告生成等通知消息。
- **公告管理功能**：用于管理员创建公告信息，确保用户及时获取重要通知。

### 二、研究内容

根据选题的内容，本次设计建议通过以下几个方面的内容进行深入研究：

1. **需求分析**。方法：通过问卷调查和学生访谈，收集学生对错题整理、错因分析与复习规划的需求和痛点。工具：利用在校资源优势，对学生群体采用随访方式收集数据，分析调查数据，确定系统的核心功能需求。
2. **系统设计**。方法：采用面向对象设计原则，进行系统模块划分，并完成数据库设计、接口设计与数据访问层设计。工具：使用 UML 工具绘制用例图、类图和时序图，确保系统的可扩展性和模块化设计。
3. **系统实现**。方法：使用 Spring Boot 框架进行开发，采用前后端分离的架构。工具：操作端为 Web 端，前端使用 Vue 3 与 Element Plus，后端使用 Spring Boot 3 与 MyBatis-Plus，数据库选用 MySQL，使用 Git 进行版本控制。
4. **系统测试**。方法：采用单元测试、集成测试和用户测试相结合的方法。工具：使用 JUnit 进行单元测试，确保每个模块功能的正确性；通过系统集成测试验证系统整体功能的稳定性和可靠性。

### 三、研究方法

- **文献研究**：查阅国内外相关文献，了解智能教育、知识追踪、个性化学习推荐以及检索增强生成技术的研究现状和发展趋势，为系统设计提供理论支持，重点关注知识图谱构建、语义检索和大语言模型应用等方面的最新研究成果。
- **框架学习**：深入学习 Spring Boot 框架的核心技术，包括依赖注入、数据持久化等，为系统开发奠定技术基础。同时，学习 Vue 3 前端框架及组件化开发的相关技术和规范，确保开发的高效性和一致性。
- **实践开发**：通过项目开发，积累实际操作经验，解决开发过程中遇到的问题，重点攻克 AI 输出结构化控制、相似题检索效果等技术难点，提升系统的稳定性和用户体验。
- **用户调研**：进行市场调研与用户调研，分析现有错题类应用的优缺点，为系统优化提供参考。通过用户反馈，持续改进系统功能和用户界面设计，确保系统能够满足用户的实际需求。
