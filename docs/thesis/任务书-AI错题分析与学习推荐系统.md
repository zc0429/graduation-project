## 选题背景及目的

（导出时：左侧窄列竖排黑体标签"选题背景及目的" + vMerge 跨本节所有段落；右侧宽列正文，宋体小四、行距固定 20 磅、首行缩进 2 字符、两端对齐。）

随着信息技术的飞快发展和教育信息化的持续推进，个性化学习已成为教育领域的重要发展方向。在日常学习中，错题是反映学生知识薄弱环节的最直接载体，对错题进行科学整理与深度分析，有助于学生精准定位知识漏洞、提升学习效率。

然而，传统的错题整理方式普遍存在明显不足：学生手工摘抄错题费时费力，难以坚持；错因分析停留在表面，无法准确对应到具体知识点；复习计划依赖主观安排；同类题目难以举一反三，导致错题重复出错。现有错题类应用多以拍照搜题、答案展示或错题收藏为主，本课题据此探索两级知识点归类、大模型解析、相似题与变式题以及固定间隔复习组成的业务闭环。系统没有实现知识图谱。

因此，本课题设计并实现一个基于智谱 GLM 模型的 AI 错题分析与学习推荐系统。系统使用 `glm-4.7-flash` 与 `embedding-3` 完成知识点归类、错因解析和同用户题库检索；相似题采用知识点、难度和向量检索组合规则，模型同步生成 3 道变式题；复习计划按第 1、2、4、7、15 天固定节点创建并通过站内消息提醒；学情报告在访问时聚合当前数据，不持久化报告历史。上述功能形成“录入—解析—推荐—复习—反馈”的学习闭环，但不把 RAG 表述为准确性保证。

### 一、研究目标

本次研究的目标是设计并实现一个基于智谱 GLM 模型的 AI 错题分析与学习推荐系统，具体实现包括以下几个方面：

- **用户管理功能**：实现学生公开注册、登录与个人资料修改；管理员可分页查询和停用用户，现有学生、教师、管理员角色按服务端权限访问。
- **科目管理功能**：用于维护系统涉及的学科信息，如数学、物理、英语等。
- **知识点管理功能**：用于维护一级章节与二级考点的两级知识点体系，为错题归类提供基础。
- **错题录入管理功能**：支持文本录入与默认关闭的多模态图片辅助录入；启用时只处理一张合规图片，`studentAnswer` 仅临时展示、不写入订正答案，须由学生确认普通表单后保存。
- **AI 解析管理功能**：系统接入智谱 GLM 模型，结合本地同用户、同科目题库检索上下文，异步生成知识点归类、错因分析与解析，并记录参考题 ID。
- **相似题推荐管理功能**：同用户范围内优先按同知识点和难度差选题，不足时使用同科目语义向量检索补充，去重后最多返回 5 题。
- **变式题管理功能**：基于原题上下文同步调用 AI，结构校验通过后保存 3 道变式练习。
- **复习计划管理功能**：按第 1、2、4、7、15 天固定节点创建复习任务，并通过站内消息提醒当天任务。
- **练习记录管理功能**：记录错题或变式题作答，按答对加 15、答错减 20 更新原题掌握度；该分值不等同于概率知识追踪。
- **学情报告管理功能**：请求时聚合当前学情周报，展示薄弱知识点、当前平均掌握度及最近一周新增错题和练习次数；定时任务只发送周报查看提示。
- **错题本导出管理功能**：支持按科目、知识点筛选导出 XLSX 错题本。
- **消息通知管理功能**：用于系统向学生发送复习提醒、周报查看提示等通知消息。
- **公告管理功能**：用于管理员创建公告信息，确保用户及时获取重要通知。

### 二、研究内容

根据选题的内容，本次设计建议通过以下几个方面的内容进行深入研究：

1. **需求分析**。方法：使用文献分析、一般业务场景分析与同类产品功能观察，结合冻结代码、数据库、接口和验证记录确定系统边界。本课题未开展正式问卷或访谈，不使用虚构样本和比例。
2. **系统设计**。方法：采用面向对象设计原则，进行系统模块划分，并完成数据库设计、接口设计与数据访问层设计。工具：使用 UML 工具绘制用例图、类图和时序图，确保系统的可扩展性和模块化设计。
3. **系统实现**。方法：使用 Spring Boot 框架进行开发，采用前后端分离的架构。工具：操作端为 Web 端，前端使用 Vue 3 与 Element Plus，后端使用 Spring Boot 3 与 MyBatis-Plus，数据库选用 MySQL，使用 Git 进行版本控制。
4. **系统测试**。方法：使用 JUnit/MySQL 集成测试、Vitest、TypeScript 检查、生产构建、Playwright Mock 与隔离库联调，并以真实智谱接口和浏览器闭环验证关键 AI 流程。Gate5 自动指标与人工盲评分开报告，人工表未填写前不宣称完成。

### 三、研究方法

- **文献研究**：查阅国内外相关文献，了解智能教育、知识追踪、个性化学习推荐及检索增强生成技术的研究现状，为两级知识点体系、语义检索和大语言模型应用提供理论背景；不将知识图谱列为当前实现。
- **框架学习**：深入学习 Spring Boot 框架的核心技术，包括依赖注入、数据持久化等，为系统开发奠定技术基础。同时，学习 Vue 3 前端框架及组件化开发的相关技术和规范，确保开发的高效性和一致性。
- **实践开发**：通过项目开发，积累实际操作经验，解决开发过程中遇到的问题，重点攻克 AI 输出结构化控制、相似题检索效果等技术难点，提升系统的稳定性和用户体验。
- **实现与证据校准**：将需求、设计和结论与冻结代码、Schema、接口、自动化测试和真实模型验证逐项对齐；同类产品仅作功能观察，未经实施的用户调研和长期效果评估不写成结果。

### 四、预期成果

1. 开发一个完整的 AI 错题分析与学习推荐系统，主要包含 Web 端的功能实现。
2. 撰写一篇详细的毕业论文，阐述系统的设计与实现过程及其在实际应用中的效果。
